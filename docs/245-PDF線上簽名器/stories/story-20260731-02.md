# 訪客 → 在 PDF 上安排一或多個簽名位置，下載簽署後的 PDF

**日期**：2026-07-31
**想法**：#245

## 互動關係

**情境**：訪客已經有可用的簽名（見 [story-20260731-01](./story-20260731-01.md)），現在要把它放到一份指定的 PDF 檔案上。

**流程**：
1. 訪客上傳一份 PDF 檔案，全程只在瀏覽器端處理
2. 訪客瀏覽文件頁面，選擇要簽名的那一頁
3. 訪客把簽名放到頁面上想要的位置，並可調整簽名的大小
4. 訪客可以重複新增簽名位置（同一頁多處，或不同頁各自簽），例如「簽名+日期」或多頁都要簽的情境
5. 訪客確認無誤後，下載簽署完成的 PDF

**業務規則**：
- 上傳的檔案若不是有效的 PDF（損毀、加密、非 PDF 格式），顯示錯誤訊息，讓訪客重新選擇檔案，不讓流程卡住或無聲失敗
- 下載的結果是一份可縮放、可列印的真實 PDF 檔案，不是圖片；除了新增的簽名，文件其餘內容與原始檔案一致
- 每個簽名位置各自獨立，訪客可以個別調整位置與大小，也可以移除某一處重來
