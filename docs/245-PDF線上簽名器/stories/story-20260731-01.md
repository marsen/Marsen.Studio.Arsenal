# 訪客 → 建立一次簽名，重複用於簽署多份 PDF 文件

**日期**：2026-07-31
**想法**：#245

## 互動關係

**情境**：訪客常需要簽署多份不同的文件（合約、表單），每一份都要放上同一個簽名，不想每次都重新手寫或重新上傳一次。

**流程**：
1. 訪客第一次使用工具時，用手寫畫布或上傳簽名圖片建立自己的簽名
2. 簽名建立後保留在訪客自己的瀏覽器中，之後不論是簽署同一份文件的其他位置、還是換一份新文件，都能直接沿用，不必重新輸入
3. 訪客可以隨時清除目前的簽名、重新建立一個新的（例如手寫版換成上傳版，或簽名寫錯要重來）

**業務規則**：
- 簽名資料只存在訪客自己的瀏覽器，不會上傳到伺服器
- 訪客尚未建立過簽名時，工具會先引導訪客建立一個，才能繼續簽署文件的流程
