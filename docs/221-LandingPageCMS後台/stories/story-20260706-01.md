# Marsen → 登入後台管理系統

**日期**：2026-07-06
**想法**：#221

## 互動關係

**情境**：Marsen 想要更新網站文案時，需要先登入後台才能進行編輯。

**流程**：
1. Marsen 造訪後台登入頁面
2. 輸入帳號密碼
3. 登入成功後進入後台管理介面
4. 帳密錯誤時看到錯誤訊息（不區分是帳號還是密碼錯，避免帳號列舉）

**業務規則**：
- 僅一組帳號密碼（Marsen 本人），不需要註冊流程、不需要多人權限管理
- 登入後在一段時間內維持登入狀態，不用每次操作都重新輸入密碼
- 未登入狀態下嘗試進入後台任何頁面，會被導向登入頁
- 登入失敗達一定次數後的處理方式：待釐清（見下）
