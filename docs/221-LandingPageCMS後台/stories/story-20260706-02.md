# Marsen → 在後台編輯首頁文案，儲存後網站立即更新

**日期**：2026-07-06
**想法**：#221

## 互動關係

**情境**：Marsen 想調整首頁（Landing Page）的標語、服務項目介紹或案例展示文字，不透過修改程式碼、commit、部署的方式。

**範圍（第一階段，首頁 + 共用的案例資料）**：
- Hero 輪播標語（每組標題 + 副標）與 CTA 按鈕文字
- 服務項目（4 項服務的標題與描述）
- 案例展示區塊文字，包含案例卡片本身的名稱／描述（此資料與 `/demos` 頁共用，編輯後兩頁同步更新）

About 頁、工具頁、以及 `/demos` 頁面本身的版面/其餘文字，**不在這次範圍內**，待這次完成後個別開子項目追蹤。

**流程**：
1. Marsen 登入後台（見 [story-20260706-01](story-20260706-01.md)）
2. 選擇要編輯的語言版本（中文或英文，一次只編輯一種）
3. 編輯對應區塊的文字內容
4. 儲存
5. 儲存成功後，網站對應語言版本立即顯示新內容，不需要重新部署

**業務規則**：
- 中英文分開編輯，切換語言標籤查看/編輯另一版本，不是雙欄同時顯示
- 儲存即發布，沒有草稿或預覽再確認發布的中間步驟
- 必填欄位（如標語文字）不可留空儲存，儲存前會擋下並提示
- 儲存失敗時（例如網路問題），Marsen 會看到錯誤訊息，網站上的內容維持原狀、不受影響
