# Marsen → 登入後台，查看聯絡表單收件匣

**日期**：2026-06-21
**想法**：#210

## 互動關係

**情境**：Marsen 打開後台（/admin）

1. 頁面顯示密碼輸入框
2. 輸入正確密碼 → 設定 session cookie，進入後台
3. 輸入錯誤密碼 → 顯示錯誤訊息

**情境**：Marsen 查看收件匣

1. 顯示所有聯絡表單送出紀錄，依時間倒序
2. 每筆顯示：email、想法描述、送出時間
3. 可以標記「已讀」

**情境**：未登入直接打開後台

1. 自動導向登入頁

**業務規則**
- 密碼從環境變數讀取
- Session 有效期 7 天
